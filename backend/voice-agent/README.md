# TakaBondhu — Realtime Voice Agent (Scam Shield Feature)

Realtime voice AI safety assistant for TakaBondhu powered by **LiveKit Agents** and **Google Gemini Realtime Voice**, tightly integrated with the **Scam Shield Deterministic Rule Engine** and **Supabase pgvector RAG** knowledge base.

---

## 🏗️ Architecture

```
Browser Microphone
       │
       ▼ (WebRTC Audio)
LiveKit Cloud Room
       │
       ▼
LiveKit Voice Agent Worker (Node.js)
       │
       ├── Google Gemini Realtime Model (Native Audio In/Out, Bangla Language)
       │
       └── scamTool: "analyze_scam_situation"
               ├── Tier 1: Deterministic Rule Engine (Verbatim Evidence Extraction)
               └── RAG Layer: Supabase pgvector Similarity Search (TakaBondhu Knowledge Base)
       │
       ▼ (Synthesized Spoken Bangla)
Browser Speaker
```

---

## 📂 Module Structure

- **`agent.js`**: Core LiveKit worker defined via `defineAgent`. Connects to room, configures the Gemini Realtime Model, attaches tools, handles session lifecycle, and delivers spoken Bangla responses.
- **`instructions.js`**: Strict system instructions enforcing the financial safety advisor role, conversational Bangla dialogue rules, and strict bans against requesting OTPs, PINs, or funds.
- **`scamTool.js`**: LiveKit tool `analyze_scam_situation` called by the AI to evaluate suspicious scenarios using the Deterministic Rule Engine and retrieve safety guidelines from the RAG knowledge base.
- **`ragTool.js`**: Direct RAG retrieval tool `retrieve_safety_knowledge` for focused queries against the 9 trusted financial safety categories.

---

## 🔒 Security & Privacy

- **No Secrets Exposed**: Frontend only receives short-lived, single-room JWT access tokens generated by `POST /api/livekit/token`.
- **Server-Side Credentials**: `GEMINI_API_KEY`, `LIVEKIT_API_SECRET`, and `SUPABASE_SECRET_KEY` stay strictly on the server.
- **Safe Logging**: No OTPs, PINs, passwords, or credentials are ever printed to logs.

---

## 🚀 How to Run the Voice Agent

### Prerequisites
Make sure `LIVEKIT_URL`, `LIVEKIT_API_KEY`, and `LIVEKIT_API_SECRET` are configured in `backend/.env`.

### Start the Worker in Development Mode
```bash
cd backend
npm run voice-agent
```
or directly:
```bash
node voice-agent/agent.js dev
```
